# Retrospective — Milestone 1

## 🟢 Apa yang Berjalan Baik?
- Setup project berjalan dengan lancar, backend, frontend, dan database sudah berhasil terhubung dalam satu sistem yang terintegrasi.
- Fitur utama seperti autentikasi dan CRUD tugas berhasil dibuat dan dapat digunakan sesuai dengan kebutuhan aplikasi.
- Docker Compose berhasil digunakan untuk menjalankan seluruh service, sehingga environment antar anggota tim menjadi lebih konsisten.
- Pembagian tugas dalam tim cukup jelas, sehingga setiap anggota bisa fokus pada perannya masing-masing.

---

## 🔴 Apa yang Perlu Diperbaiki?
- Komunikasi tim masih kurang konsisten, terkadang terjadi miskomunikasi
- Penggunaan Git workflow belum terstruktur di awal, masih ada yang push langsung ke branch main.
- Proses testing masih terbatas dan belum mencakup semua kemungkinan error.
- Dokumentasi project masih perlu dilengkapi agar lebih mudah dipahami.

---

## 🔵 Action Items untuk Milestone 2
- Menggunakan Git workflow (branch, pull request, code review) secara konsisten untuk setiap perubahan.
- Meningkatkan komunikasi tim melalui koordinasi yang lebih rutin.
- Melakukan testing sebelum setiap perubahan di-merge ke main.
Melengkapi dan memperbarui dokumentasi project secara berkala.
